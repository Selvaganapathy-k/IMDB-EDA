

# 🎬 Exploratory Data Analysis on IMDB Top 1000 Movies

## 📌 Project Description

This project performs **Exploratory Data Analysis (EDA)** on the **IMDB Top 1000 Movies dataset** using Python.
The goal is to analyze movie trends, ratings, genres, and other key attributes to gain meaningful insights through data cleaning, analysis, and visualization.

This project is created as a **mini project** for academic learning and hands-on practice in data analysis.

---

## 📁 Dataset Information

* **Dataset Name:** IMDB Top 1000 Movies
* **File:** `imdb_top_1000.csv`

The dataset includes information such as:

* Movie title
* Genre
* IMDB rating
* Director
* Cast
* Release year
* Runtime
* Votes
* Gross earnings

## 🔍 Analysis Performed

* Dataset loading and inspection
* Handling missing values
* Data cleaning and preprocessing
* Analysis of movie ratings and votes
* Genre-wise analysis
* Year-wise movie trends
* Data visualization using charts and graphs

---

## 📈 Key Insights

* Certain genres consistently receive higher IMDB ratings
* Movies with higher votes tend to have better ratings
* Movie production trends vary across years
* A small set of directors appear frequently in top-rated movies
